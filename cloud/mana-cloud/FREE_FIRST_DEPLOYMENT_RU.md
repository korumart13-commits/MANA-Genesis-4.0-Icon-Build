# Бесплатный запуск MANA — без покупки домена и сервера

## Что можно получить бесплатно

- Cloudflare Workers Free: бесплатный тариф с ограничениями. По опубликованным лимитам сейчас — до 100 000 запросов в сутки на аккаунт; лимиты и условия могут меняться.
- Адрес платформы вида `*.workers.dev` — без покупки собственного домена.
- HTTPS на платформенном адресе.
- Статические файлы сайта и небольшой Worker API в одном проекте.
- GitHub Free для публичного репозитория и хранения исходников.

## Что НЕ становится бесплатным автоматически

- OpenAI API/GPT: ChatGPT Free и OpenAI API — разные продукты. API тарифицируется отдельно; бесплатные API-кредиты доступны только если они явно отображаются в API-аккаунте или предоставлены по отдельной программе.
- Большие локальные модели: их можно запускать без оплаты API на совместимом смартфоне, но загрузка модели расходует мобильный интернет и память/энергию устройства.
- Собственный домен: не нужен для первого запуска, если использовать адрес workers.dev.
- Платный Cloudflare Workers тариф: для прототипа не включать.

## Рекомендуемая конфигурация

1. Зарегистрировать бесплатный аккаунт Cloudflare.
2. Не добавлять платный тариф и не подключать собственный домен.
3. Создать Worker, подключив публичный GitHub-репозиторий `korumart13-commits/MANA-Genesis-4.0-Icon-Build`.
4. Указать корневую директорию проекта: `cloud/mana-cloud`.
5. Настроить секреты только в настройках Worker:
   - `OPENAI_API_KEY` — необязателен для публикации сайта; нужен только для облачных GPT-запросов.
   - `MANA_DEVICE_TOKEN` — нужен для тестирования закрытого GPT endpoint.
6. Оставить `MANA_GPT_MODEL` на значении из wrangler.toml либо выбрать модель, доступную API-аккаунту.
7. Развернуть и проверить `/api/health`.

Если OpenAI API-ключа нет или API-биллинг не настроен, сайт и локальный режим MANA всё равно могут быть доступны; облачный GPT endpoint должен возвращать понятную ошибку конфигурации, а приложение — переключаться на локальную модель.

## Важное про «полностью бесплатно»

Нельзя честно обещать бесплатный GPT API без явного бесплатного кредита/лимита. Бесплатный хостинг — это только инфраструктура. Для режима без расходов используйте локальную модель на телефоне и не вызывайте платные облачные API.

## Ограничения прототипа

- Worker не является полноценной базой данных, аккаунт-системой или облачной синхронизацией истории.
- Сейчас используется один тестовый bearer-токен; не встраивать его в публичный APK. Для реального выпуска нужны индивидуальная регистрация устройств, ключи на Android Keystore, отзыв и ротация доступа.
- Не отправлять личные данные и содержимое контактов/уведомлений в облако по умолчанию.
- У Cloudflare Free есть лимиты; платный план не включать без отдельного решения владельца.
- Сервис ещё не развёрнут: появление реального публичного адреса возможно только после авторизации владельца аккаунта и запуска deployment.

## Мобильная регистрация

Все шаги выполняются в браузере смартфона. При подключении GitHub Cloudflare перенаправит пользователя на GitHub для авторизации приложения и выбора репозитория. Пользователь должен лично подтвердить доступ.

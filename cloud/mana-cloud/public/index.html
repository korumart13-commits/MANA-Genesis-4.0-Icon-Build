Операционная система Мартыновы

MANA объединяет локальный интеллект смартфона и облачные модели GPT в одном ассистенте. Локальные модели могут работать на устройстве автономно, а облачный канал подключается для задач, которым нужны дополнительные возможности.

Одна MANA — два вычислительных контура

MANA Engine · смартфон

Локальные модели, приватная память, голос, аватар и Android-инструменты. Локальные данные остаются на телефоне, пока пользователь не разрешит их передачу.

MANA Cloud · сервер

Защищённый шлюз к официальному API GPT. Сервер не содержит веса GPT и не подменяет локальный движок — он передаёт запросы и возвращает ответы.

Общий контекст

Приложение может передать выбранный фрагмент локального контекста в облако, а затем передать ответ GPT обратно локальной модели для дальнейшей обработки.

Защищённое подключение

Обмен выполняется по HTTPS. Секрет API GPT хранится только в серверном хранилище секретов, а не в APK или браузере. Запросы к GPT требуют токен авторизованного устройства. Не отправляйте сюда пароли, приватные ключи или резервные коды.

Для реального запуска администратор должен настроить секреты OPENAI_API_KEY и MANA_DEVICE_TOKEN. Этот демонстрационный шлюз использует общий токен одного устройства; перед подключением нескольких устройств нужна отдельная регистрация ключей и отзыв доступа по каждому устройству.

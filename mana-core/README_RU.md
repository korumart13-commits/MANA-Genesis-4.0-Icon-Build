# MANA Core 4.0 — отдельное ядро

Самостоятельный Kotlin/JVM-модуль центрального ядра MANA Genesis. Он отделён от интерфейса Mana, аватара, лаунчера и Android-оболочки: сначала собирается и проверяется ядро, затем вокруг него подключаются приложения и системные адаптеры.

## Реализовано
- жизненный цикл ядра: запуск, работа, остановка и диагностика;
- единый вход для запросов и цепочка провайдеров с приоритетом по порядку (GPT первым, локальная модель второй);
- fallback при недоступности или ошибке основного провайдера;
- интерфейс памяти и ограниченное хранилище в памяти процесса;
- реестр только явно зарегистрированных read-only инструментов;
- запрет side-effect инструментов в read-only реестре;
- валидация входных данных, отмена запросов и unit-тесты.

## Пока не включено
- реальный GPT-клиент и MANA Gateway;
- загруженная LiteRT-LM модель и её веса;
- постоянное Android-хранилище;
- Android-службы, UI, аватар и голос;
- Linux kernel, device tree, vendor blobs и прошивка RMX5566.

Это готовая основа-оркестратор, а не сама языковая модель. GPT и LiteRT-LM подключаются отдельными адаптерами. API-секреты нельзя помещать в APK.

## Сборка
Требуются JDK 17 и Gradle 8.10.2. Выполнить в этой папке: gradle clean test build.
